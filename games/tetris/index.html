怎么玩

🎮 目标

把方块拼满横着的一整行，那一行就会消除得分。把得分越堆越高！

📱 手机和平板

  • 单指拖动 — 移动方块（上下左右都可以）
  • 双指拧 — 转动方块的角度
  • 按住 — 自动暂停，松手继续
  • 右上 ⚙ — 打开设置（速度、主题、模式…）

🖱 鼠标（电脑）

  • 鼠标拖动 — 移动方块
  • 按住 — 自动暂停
  • 屏幕底部方向板 — 点 ← → ↓ 移动，点 ↺ ↻ 旋转

⌨️ 键盘（电脑）

  • ← → ↓ 或 A D S — 左右移动 / 加速下落
  • ↑ / W / 空格 — 顺时针转
  • Z — 逆时针转
  • P — 暂停 / 继续
  • Esc — 关掉面板
  • Enter — 确认

🌈 设置里有啥

  • 速度 — 砖块下落多快
  • 上拉容忍 — 拼错了可以往回拉几格
  • 结束模式 — 标准 = 堆到顶就结束；无尽 = 永远玩
  • 色彩主题 — 童趣 / 糖果 / 夜空
