怎么玩

🎮 目标

让球弹来弹去把砖块都打掉，连击越长得分越高。

📱 手机和平板

  • 左右拖动 — 移动板拍（按住也不暂停，球继续飞）
  • 倒计时时拖板拍 — 偏离起点的方向 = 球发射方向（虚线箭头预览）
  • 顶栏 ⏸ — 暂停 / 继续
  • 右上 ⚙ — 打开设置

🖱 鼠标 / ⌨️ 键盘

  • 鼠标拖动 — 移动板拍
  • ← → / A D — 移动板拍
  • P — 暂停 / 继续
  • Esc — 关掉面板
  • Enter — 确认

🎁 道具

  • 🟪 加宽板拍 — 板拍变宽 12 秒
  • 🌟 多球 — 当前每颗球各分裂一颗
  • 🐌 慢球 — 球速变慢 10 秒

🏁 模式

🎯 标准 = 砖块压到板拍就结束 · ♾️ 无尽 = 压到板拍清上半区继续
